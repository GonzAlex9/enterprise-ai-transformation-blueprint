# 90-Day Delivery Roadmap

## Goal

End 90 days with:

- a prioritized AI portfolio;
- shared architectural foundations;
- 1–2 measured pilots;
- governance operating in practice;
- evidence for scale / hold / redesign / stop decisions.

## Days 0–30 — Discover and baseline

### Business

- align executives on outcomes;
- select 3–5 priority processes;
- run process-mapping workshops;
- baseline current KPIs;
- assign process owners.

### Technology

- inventory systems and data;
- classify sensitive information;
- review identity and access;
- identify reusable APIs;
- define an approved model-access pattern.

### Governance

- define risk tiers;
- define a minimum pilot gate;
- create an initial AI use-case register.

### Deliverables

- process maps;
- candidate portfolio;
- prioritization score;
- baseline metrics;
- first target architecture;
- pilot charter.

## Days 31–60 — Build controlled pilots

### Pilot A — Customer support copilot

- knowledge retrieval;
- CRM read context;
- cited draft response;
- human review.

### Pilot B — Invoice exception triage

- document extraction;
- deterministic validation;
- exception routing;
- human handling for unresolved cases.

### Shared engineering foundations

- identity;
- model gateway;
- tool contracts;
- observability;
- eval harness;
- audit pattern.

### Deliverables

- working pilots;
- offline eval results;
- latency and cost baseline;
- security/privacy review;
- user-feedback sessions.

## Days 61–90 — Measure and decide

Compare pilots against baseline:

- cycle time;
- user adoption;
- correction / override;
- quality;
- cost;
- critical failures.

For each pilot choose:

```text
Scale | Hold | Redesign | Stop
```

Document reusable components and ownership before Wave 2.

## 90-day outcome

Success is not:

> "We launched two AI demos."

Success is:

> **"We know which use cases create value, which controls are required, which platform capabilities are reusable and what should scale next."**
